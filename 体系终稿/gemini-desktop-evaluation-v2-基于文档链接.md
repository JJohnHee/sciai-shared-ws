## 风险盲区五处高危明细（Gemini 从文档中挖出）

1. **状态易失**：hub.mjs 的 nodeRegistry 纯内存存储，进程重启即丢失节点拓扑（进度总览 §二、§七）
2. **零回归防护**：面对 77 节点与高频迭代，E2E 测试为 0（README §六）
3. **高权限单点密钥与无沙箱暴露**：所有 *-cf 节点共用同一把公钥 id_opc_mesh_global（全体系解剖 §2.1），hub.mjs 直接暴露网页终端 /api/term/* 与远程文件 /api/fs/*（进度总览 §二），admin 权限体系为 0
4. **静默模型投毒与合规风险**：依赖 DeepSeek 网页逆向（:18960）、不可控 keyless 中转及会动态换皮的上游模型，文档未见敏感数据脱敏网关或路由前指纹门禁
