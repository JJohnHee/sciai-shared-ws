3. 效果：hub 重启自动恢复 4 节点注册，无手动操作

**工作量**：1-2h（改 hub.mjs 20 行 + test）

### **P2：OPC 多文件夹布局适配**（✓核心大需求）
**现象**：部门主管工作区分散（oneyear=/root/sciai-hub、i9=/home/opc/clawsos_ws、lx-6=/home/opc/clawsos_ws），导致：
- claude 工作目录混乱（CLAUDE.md 位置不统一）
- pool.mjs 派任务时 cwd 假设不成立（vm2 派发到 i9 时 pwd 是 /root）
- 知识库入库路径（ego-kb）每个节点不同

**正解**：统一"三级目录结构"
```
{NODE_ROOT}/
  clawsos_ws/              # 通用工作区（CLAUDE.md、skills、kb 冰）
    CLAUDE.md              # 节点本地 agent 运行手册
    .claude/skills/        # 节点私有技能库
    kb/                    # 本地知识库根
  clawsgo-replica/         # oneyear only（pool.mjs、DEPARTMENTS.md）
  .zcode/cli/skills/       # 全局技能库（symlink 或 copy）
```

**行动清单**：
1. i9/lx-6/lx7 上 mkdir -p ~/clawsos_ws/.claude/skills && mkdir -p ~/clawsos_ws/kb
2. 把 CLAUDE.md / scios-research skill 拷到各节点 ~/clawsos_ws/
3. claude 命令改 cwd：`claude -p ... --cwd ~/clawsos_ws`
4. pool.mjs 派任务脚本统一 `cd $NODE_WS/clawsos_ws &&`

**工作量**：2-3h（布局 + 脚本改造 + 验证一次派发）
